## 中文

- 修复快速删除文件、目录时间戳未及时变化时的旧入口缓存失效问题。

- 启动和 F5 改为轻量增量检查，复用安装目录索引，只重新识别新增、变动或入口失效的目录；运行期间合并目录变更通知。
- 扫描浮层分开显示游戏库数量、本次确认数量、当前目录及封面完整度，并提示缺失封面的游戏。
- 工具按钮和按键提示集中到自适应左侧栏；改进搜索、窗口拖动、全屏切换及悬浮滚动条。
- 可设置宫格列数，默认9列，窗口变窄时自动减少。
- 全屏启动画面在游戏打开后定格，游戏结束后返回游戏库；保留手动关闭，增加退出中的提示。
- 补充游戏中文名、封面和启动入口识别；启动配置使用相对安装路径。

注意：启动器关闭期间发生的复杂深层目录调整，普通索引可能无法立即发现。首次无索引或索引失效时仍需重新识别目录。

## English

- Startup and F5 reuse installation indexes and rescan only new, changed or invalid installations. Runtime directory notifications are coalesced instead of polling the disk while idle.
- Scan notifications show library/discovery counts, the current directory, cover totals and missing artwork names.
- Responsive left toolbar and input hints, improved search, window dragging, fullscreen restoration and overlay scrollbars.
- Configurable grid columns, defaulting to nine with fewer columns in narrow windows.
- Fullscreen launch artwork pauses after the game opens and returns to the library after exit, with manual dismissal and exiting status.
- Improved Chinese titles, artwork and executable matching, with portable relative launch profiles.

Limitation: complex nested changes made while GAMES is closed may not be detected immediately. Missing or invalid indexes still require discovery.

Validation: 294 isolated regression checks and native launcher integrity tests passed locally. Windows x64 requires .NET Framework 4.8 or later.
